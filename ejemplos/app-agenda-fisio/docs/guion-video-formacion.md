# Guion del vídeo de formación (8–10 minutos)

Graba con la cuenta de administración y una de recepción, con datos ficticios.

| Tiempo     | Contenido                                                                                                                                                                      |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 0:00–0:45  | **Presentación.** Qué es Agenda Fisio, qué sustituye (la agenda de papel y el Excel) y los dos tipos de cuenta.                                                                |
| 0:45–1:30  | **Entrar** desde el ordenador y desde el móvil. Menú: Agenda, Pacientes. Cerrar sesión.                                                                                        |
| 1:30–3:00  | **Recepción: alta de un paciente.** Nombre y teléfono, guardar, buscarlo. Enseña un error de validación (teléfono corto).                                                      |
| 3:00–4:45  | **Recepción: crear una cita.** Buscar paciente, fisioterapeuta, hora y duración. Provoca un solape y muestra el mensaje; después crea una cita contigua. Reprogramar una cita. |
| 4:45–6:15  | **Fisioterapeuta: la agenda.** Día y semana, selector de fisioterapeuta, «Pendiente de marcar». Marcar realizada, cancelada y no presentada.                                   |
| 6:15–7:15  | **Dueña: pacientes sin volver.** Qué significa «más de 60 días», llamar desde el móvil, crear una cita desde la ficha.                                                         |
| 7:15–8:45  | **Administración.** Alta de cuentas y marca «Atiende citas», bloqueo, exportar datos de un paciente, eliminar un paciente (aviso de borrado de citas), actividad.              |
| 8:45–9:30  | **Datos de salud y privacidad.** Notas clínicas, `/privacidad`, no compartir datos fuera de la aplicación.                                                                     |
| 9:30–10:00 | **Ayuda y siguientes pasos.** Contacto de soporte (PENDIENTE(empresa)), recordatorios y facturación quedan para una futura versión.                                            |

Consejos: usa pacientes ficticios; muestra siempre un caso correcto y uno de error; no grabes pantallas con datos reales.
